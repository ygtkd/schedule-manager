プライバシー・利用条件

予定の自動管理アプリは仮公開中です。

取得する情報と目的

Googleアカウントの識別子・メールアドレスを認証時に受け取り、識別子から利用者別の保存領域を作成します。メールアドレスは認証判定に使い、通常の保存データには記録しません。Googleのアクセス許可に基づき、ご自身のメインカレンダーの予定を取得・作成します。

LINE連携時には送信者IDをハッシュ化してGoogle利用者と対応付けます。連携した公式アカウントへのテキスト送信だけを受信します。

AIへの送信

Web画面で同意した本文、またはLINE受信を有効にした利用者のメッセージを、件名・日時・場所の抽出のためGoogle Gemini APIへ送信します。Gemini無料枠では送信内容が製品改善に使われる場合があります。機密情報や他人の個人情報を送らないでください。

Google APIから取得した情報は、Google API Services User Data PolicyのLimited Use要件に従って取り扱います。取得したカレンダーの予定はGeminiへ送信しません。

保存と削除

Googleの継続アクセス用トークンと未処理LINE本文は暗号化してAzure Cosmos DBに保存します。LINE本文は処理完了後に削除し、未処理分と処理履歴は原則30日で期限切れになります。セッションは7日、LINE連携コードは10分です。会員識別子と設定は連携を継続するため保存します。

設定画面からGoogleの連携を解除すると、保存したGoogleトークンを削除し、セッションを無効化してLINE連携を解除します。既にGoogleカレンダーに作成された予定は削除しません。履歴などは保存期限まで残ります。開始済みの処理は解除後に完了する場合があります。

利用上の条件

抽出結果には誤りがあり得ます。自動登録を有効にする前に内容をご確認ください。無料利用枠をアプリ全体で共有しており、制限に達すると処理が停止・遅延します。LINE処理は約30分ごとに1件で、即時性や処理の完了を保証するものではありません。

運営・問い合わせ

運営：ygtkd。問い合わせ・保存データの削除依頼はGitHub Issuesをご利用ください。公開されるため、メッセージ本文・メールアドレス・連携コード・トークンは記載しないでください。
